# 失效分析

| 失效 | 影響 | 檢測 |
|---|---|---|
| 35 mm 不足抽出 | 換杯撞探頭 | H1：V2 反例與 V3 最低端高度 |
| 用圓弧抽出 | 玻璃撞瓶口 | H1/H3：XY 不變、全段掃掠 |
| 探頭提到自己的腕關節 | 途中卡住 | H3：包含本頭固定關節 |
| 滑塊離開導桿 | 掉落或失去剛性 | H4：導桿／滑塊全行程包絡 |
| 共用父物件 | 另一頭被帶動 | H2：另一頭全零件矩陣 |
| 檢查物件名稱漏選 | 空集假通過 | 所有族群數量下限與名稱記錄 |
| 列印件水密但未連接 | 無法裝配承力 | H6：介面／五金／載荷獨立驗證 |
