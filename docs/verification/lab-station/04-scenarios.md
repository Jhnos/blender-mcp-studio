# Given / When / Then

S1：Given 兩頭浸入同杯，When 僅左頭升 0→100 mm，Then 左頭 XY 不變、所有探頭清杯、右頭全件不變。以 5 mm 步距量測，另用掃掠體補足兩取樣間。

S2：重設，交換左右頭，重複 S1。

S3：兩頭皆升起；核對換杯空間，拍攝 probe-raised.png。

S4：在浸入與提起姿態分別檢查螢幕 0–75°；單純舊姿態通過不等於加導軌後通過。

負對照：V2 最高 35 mm 不足；把升程減回 35 mm 必須失敗。不得只驗證增加了控制屬性。

S5：Given 夾爪五金尚未裝入，When 沿軸裝入螺栓與螺母，Then 裝入掃掠不穿過探頭或其他零件；襯套上下止口保留、導桿兩端均有止擋。

S6：Given 已退出夾爪螺栓，When 雙頭升起、另一頭外轉 45°、待拆頭降下並打開夾蓋 25 mm，Then 夾蓋與對應半襯的取樣運動無表面干涉。
