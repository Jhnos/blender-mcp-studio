# v2 — 可證偽假設

> 回導航 [[hand-framework/v0-INDEX]] · 相關 [[hand-framework/v3-failure-modes]]、[[hand-framework/v7-matrix]]

每一條都寫成**可以被推翻**的形式。寫不成可推翻形式的,不是假設,是願望。

## P0(不成立就整個框架沒有意義)

| ID | 假設 | 推翻它的觀察 |
|---|---|---|
| HF-1 | 規格→規劃→執行三層能**逐面數、逐尺寸**重現 `models/hand-v3/` | 四個 STL 任一面數不等,或尺寸差 > 0.1 mm |
| HF-2 | V3 的兩份契約能從規劃層**完整生成**,不需任何手打字面值 | 生成器輸出與簽入 JSON `json.loads` 後有任何 diff |
| HF-3 | 精簡連桿能組成通過同一套契約的**整手**(不只指節) | `hand_compact.json` 真機任一 FAIL,或掌盤擺位在 `strict=True` 下無解 |

## P1(影響設計品質,不影響可行性)

| ID | 假設 | 推翻它的觀察 |
|---|---|---|
| HF-4 | 有梯度的手指建得出,且 V3 的單一零件號性質不受影響 | V3 契約 `shared_mesh` 觀測 ≠ 1,或梯度實例的零件號數 ≠ 相異力矩臂數 |
| HF-5 | 掌盤五條新不變式對 V3 逐位元組中性 | `test_palm_v3`、圖表守衛、包測試任一紅 |
| HF-6 | 佈局換行算術搬出 bpy 後,結果與現況相同 | `LayoutPlan` 算出的佔地 ≠ 真機量到的 242.0 × 103.5 |
| HF-7 | 契約閘門進 `--real` 的成本可接受 | 首跑實測 > 10 分鐘(那就觸發 D-004 的另一半:只留參考對) |

## P2(值得知道,不擋路)

| ID | 假設 | 推翻它的觀察 |
|---|---|---|
| HF-8 | 精簡實例的拇指擺位掃得出通過對生判準的解 | 掃描空間內無任何組合滿足 `thumb_index_tip_gap_mm < pinch_contact_mm` |
| HF-9 | 精簡實例的佈局(四件)放得進 256 床身 | `layout_fits_bed` FAIL |

M6 結果:HF-3、HF-8、HF-9 全部成立(見 [[hand-framework/v8-results]]);HF-8 多了一層——可達不等於靜止時不撞。

推翻 HF-8 是**發現**不是失敗:那表示 15 mm 深的掌盤需要不同的拇指幾何,寫進 [[hand-framework/v8-results]]
的「推翻了什麼」,不做 fallback。
