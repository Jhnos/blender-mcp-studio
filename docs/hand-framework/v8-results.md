## 面數抖動探針(FF-18,2026-09-09)

在常駐 Blender 裡用產生器自己的 `realise`/`boolean`/`cleanup_mesh` 重建精簡指節,逐步記面數與頂點雜湊:

| 探針 | 觀察 |
|---|---|
| 產生器整跑 ×3,逐物件 | 15 個手單元與散裝指節每次都變:基節 2976/2978、遠節 2984/2986;掌盤三次頂點雜湊完全相同 |
| 單零件重建 ×4(安靜場景) | 面數逐步全等(2978 / 2984) |
| 單零件重建 ×8(每步 view_layer.update + 匯出) | 面數逐步全等,但**頂點雜湊從第一個 UNION 起就分歧**(6 種) — exact solver 輸出順序不定 |
| V3 對照 ×3 | 逐步全等 3434;V3 的碎片離 cleanup 門檻夠遠,所以從來沒抖 |

結論:抖動是宿主的,不是規格的;一個零件最多差一個碎片四邊形(2 面)。預算 = 2 × 布林零件數,由 `sliver_budgets(instance)` 從規劃算出。
