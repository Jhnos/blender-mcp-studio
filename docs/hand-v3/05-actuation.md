# 05 — 致動:腱力預算與硬體

> 回導航 [[hand-v3]] · 相關 [[hand-v3/03-finger]]、[[hand-v3/06-softlayer]]

## 為什麼這一頁大部分是空的

腱力預算是從**抓持力需求**倒推的,而抓持力需求要等 Track 1 量到
「充氣能貢獻多少」才知道。這一頁刻意留白,不用猜的數字填。

**這正是分軌的理由**:先量,再選硬體。

## 已經知道的架構

充氣夾層把工作拆成兩半,這是它最大的價值:

| | 誰做 | 需要什麼 |
|---|---|---|
| **定位**(把手指包到物體上) | 腱 + 伺服 | 行程夠、力量小 |
| **夾持**(不讓它滑掉) | 夾層氣壓 | 壓力夠、**不耗電** |

伺服只要能把手指帶到位,不必一直出力維持夾持——**封閉氣室保壓不耗電,
伺服維持堵轉扭矩要一直吃電流而且會發熱**。所以伺服可以選小的。
這對一隻靠細線驅動的手是關鍵優勢。

## 已知的限制

- InMoov 用的是標準規格伺服(HK15298 只有 90° 行程,MG996R 有 180°)`[親驗]`,
  線材是編織釣魚線 200 lb。這給了 Track 1 一個現成的起點。
- InMoov 每指**兩條**線(上下各一)`[親驗]`,與 V3 的單腱前提不同。
  Track 1 沿用它的雙線,Track 2 才改單腱——**兩者的量測結果不能直接互比**,
  這一點必須寫進台架記錄,見 [[hand-v3/v8-results]]。

## 待填(等 Track 1)

| 項目 | 怎麼決定 |
|---|---|
| 每指所需腱力 | 台架量到的滑脫力 ÷ 力矩臂 |
| 伺服型號與扭矩 | 上一列 × 安全係數 |
| 腱材與直徑 | 由腱力與最小轉彎半徑共同決定 |
| 致動器行程 | 由 [[hand-v3/03-finger]] 的腱路徑長變化決定 |

## 安全

- 欠致動的手指會把全部馬達扭矩送到**還沒被擋住的那個關節**。手指伸進閉合路徑
  會被夾傷,所以**馬達要限流**,不是靠小心。
- 預張的腱斷掉會回彈。張線時戴護目鏡,並且讓線的走向使斷裂不會掃到人。
