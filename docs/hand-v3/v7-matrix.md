## 怎麼讀狀態欄

- **TODO** = 還沒做。不是「大概有被別的測試涵蓋」——那句話正是漏洞的來源。
- H6 是**反過來**做的:氣囊本體的厚度要台架量,但「厚到多少就擋住閉合」是純幾何,今天就算得出來。
  全屈時相鄰指節的掌側面只剩 3.39 mm,所以夾層每側 **1.70 mm** 是上界——買手套時要遵守的就是這個數字。
- F9 的轉彎半徑**就是**力矩臂(6.6 mm),不是另一個要量的量;缺的是門檻,而門檻是線材的性質,
  屬於採購決定不是計算。買定線材的那一刻,這一列自動有答案。
- F10 兩兩最小淨距 10.40 mm,而且**任何讓它變小的規格都會先被 `HingePhalanxSpec` 的不變式擋掉**。
  所以那條檢查斷言的是「會被拒絕」而不是「距離夠大」:沒有任何合法輸入能弄紅的檢查,等於 `assert True`。
- ES-2 原本寫「三個力矩臂 (7.0, 5.5, 4.0) 嚴格遞減」並標 PASS,而力矩臂早就改成
  **兩個且相等**:5.5 / 4.0 會讓壁厚只剩 1.85 / 0.35 mm,低於 2.4 的最小值。改成相等
  是為了十五個指節共用一個零件號。**需求被量測推翻,而那一列還掛著 PASS**——
  被推翻的需求要改寫需求,不是留著它繼續宣稱通過。
- **vacuous** = 跑了但母數為零。**不算 pass**。
- 只有寫著 **PASS 並附數字**的列才算數。
