# v3 — 失效模式表(它會怎麼壞)

> 回導航 [[hand-v3/v0-INDEX]] · 相關 [[hand-v3/v2-hypotheses]]、[[hand-v3/v4-scenarios]]

先列「它會怎麼壞」,每個失效模式各配一個夾具與一條斷言。
**只測快樂路徑,只能證明「沒有東西壞的時候它不會壞」。**

本專案已經踩過的坑優先列在最前面——那些不是假想,是紀錄。

## 已經發生過的失效類(來自 `docs/LESSONS_LEARNED.md`)

| ID | 失效模式 | 誰會抓到 |
|---|---|---|
| F1 | **改了規格參數,但讀它的程式沒跟上** → 規格測試全綠而網格是錯的 | 斷言落在**產出物**上,不是規格上(H3、H4 的 artifact 驗證器) |
| F2 | **不改變外形包絡的特徵,尺寸量測對它全盲** → 倒角、孔、墊改了但 bbox 沒動 | 用面數／體積／射線驗,不用尺寸讀回 |
| F3 | **拿「面」的距離當包絡** → 量到最近點不是最遠點 | 包絡半徑由**最遠頂點**算 |
| F4 | **靜態無碰撞不等於運動包絡成立** | 全行程掃掠,不是只驗中立姿態 |
| F5 | **兩個推導量剛好相等** → 相切而非相交,布林解不出來 | 把「恰好相等」當不變式擋住 |
| F6 | **閘門本身沒有鑑別力** → 掃法向被孔壁的法向蒙混過去 | 每個新閘門都要用**故意弄壞的輸入**證明它會紅 |

## V3 特有的失效模式

| ID | 失效模式 | 夾具 | 斷言 |
|---|---|---|---|
| F7 | 腱路徑長變化超過致動器行程 → 手指**永遠關不起來**,而每個零件單獨看都對 | 全伸與全屈兩個姿態 | 路徑長差 ≤ 行程(ES-1) |
| F8 | 力矩臂比值反了 → 手指從指尖捲起,抓不住東西 | 三個關節的力矩臂 | 單調遞減(ES-2) |
| F9 | 腱在掌盤裡的轉彎半徑太小 → 線磨斷或卡死 | 五條腱路徑 | 最小轉彎半徑 ≥ 門檻 |
| F10 | 兩條腱路徑相交 → 互相摩擦 | 同上 | 任兩條不相交 |
| F11 | 充氣後外形擋住閉合 → 裝上手套反而抓不到東西 | 夾層偏移面 | 掃掠無重疊(PS-4) |
| F12 | 進氣口被內部結構擋住 → 打不進氣,而外觀完全看不出來 | 射線探針 | 貫穿(ES-4) |
| F13 | 拇指指尖碰不到食指指尖 → 這隻手不能對指 | 兩指可達區域 | 相交(PS-3) |
| F14 | **母數為零被當成通過** → 一次都沒量到,比率算出來是 1.0 | 台架記錄 | 先驗母數 > 0,零則標 vacuous |
| F15 | 台架兩組共用同一隻手套 → 量到的差異是污染不是變數 | 兩組獨立手套 | 記錄裡標明手套編號 |
| F16 | InMoov 的 STL 被誤提交進版控樹 → 非商業條款傳染 | git 追蹤清單 | 版控樹裡沒有 InMoov 檔案 |
| F17 | V3 的改動伸手進 V1／V2／V6 | 凍結包 checksum | 四份迴歸契約全綠(ES-6) |

## 用法

新增任何一片幾何之前,先問「它會怎麼壞」,在這張表補一列,再去寫那條會紅的測試。
**表上沒有的失效模式,等於沒被想過。**
