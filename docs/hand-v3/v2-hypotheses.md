# v2 — 可證偽假設

> 回導航 [[hand-v3/v0-INDEX]] · 相關 [[hand-v3/v3-failure-modes]]、[[hand-v3/v7-matrix]]

每一條都寫成**可以被推翻**的形式。寫不成可推翻形式的,不是假設,是願望。

## P0(不成立就整個 V3 沒有意義)

| ID | 假設 | 推翻它的觀察 |
|---|---|---|
| H1 | 夾層充氣會讓滑脫力顯著上升 | 配對比較的信賴區間跨過 0 |
| H2 | 外層不可延展時,H1 的效果明顯大於外層彈性時 | 兩組外層的效果量差異不顯著 → [[hand-v3/06-softlayer]] 的封頂說法要改寫 |
| H3 | 一條腱能把三個指節從全伸帶到全屈 | 腱路徑長變化超過致動器行程,或掃掠到不了全屈 |

## P1(影響設計品質,不影響可行性)

| ID | 假設 | 推翻它的觀察 |
|---|---|---|
| H4 | 彈簧勁度梯度能讓指節依序閉合(近端先) | 掃掠取樣顯示遠端先動,或順序不穩定 |
| H5 | 抽真空的效果與加壓同級 | 兩種氣壓方向的滑脫力差異顯著且抽真空明顯較差 |
| H6 | 充氣後的外形不擋住手指閉合 | 偏移面掃掠出現重疊 |
| H7 | 拇指指尖與食指指尖的可達區域相交 | 幾何計算顯示不相交 → 這隻手不能對指 |

## P2(好有,沒有也能交)

| ID | 假設 | 推翻它的觀察 |
|---|---|---|
| H8 | 一次充氣能維持十秒以上不需補打 | 壓力衰減曲線在十秒內掉到基線 |
| H9 | 20 mL 針筒比 60 mL 有效(壓力較高) | 兩者滑脫力無顯著差異 |

## 不是假設的東西

「這隻手很好用」「抓得很牢」——沒有可推翻的形式,所以不進這張表。
它們屬於 Lane B,交使用者裁,不假裝量化。
