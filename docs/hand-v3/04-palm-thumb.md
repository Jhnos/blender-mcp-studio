# 04 — 擬人掌盤與對生拇指

> 回導航 [[hand-v3]] · 相關 [[hand-v3/03-finger]]、[[hand-v3/07-interfaces]]

## 為什麼不能沿用 V2 的掌盤推導

V2 的掌盤是**正五邊形**,尺寸由一條式子決定:內切圓半徑要能容下
「站位半徑 + 承接座包絡 + 壁厚」,再由正多邊形的對稱性推出外接圓。
那條推導的每一步都假設**放射對稱**。

四指一排加一個對生拇指**沒有放射對稱**,所以那條式子一個字都不能用。
V3 的掌盤要重新推導,而且約束不同:

| V2 的約束 | V3 的約束 |
|---|---|
| 五個站位等分圓周 | 四個指根**共線**,間距由指寬決定 |
| 每個站位一樣 | 拇指站位**不在那條線上**,而且轉了一個對生角 |
| 掌盤厚度由承接座決定 | 同左,但還要容下四條腱的匯流路徑 |

## 對生拇指是什麼

拇指要能**面對**其他四指,而不是跟它們平行。這需要兩個角度,不是一個:

- **對生角**:拇指的彎曲平面與四指彎曲平面的夾角。
- **掌側傾角**:拇指基座從掌面抬起的角度。

兩個角度合起來決定「指尖能不能碰到其他指尖」,那是拇指存在的唯一理由,
也是唯一有意義的驗收條件:**拇指指尖與食指指尖的可達區域必須相交**。
這是幾何量,Lane A 驗得了(對應 [[hand-v3/02-requirements]] 的 PS-3)。

## 腱要從掌盤穿出去

四指加拇指是五條腱,全部要匯到手腕。V2 的掌盤有一個中央通道加每臂一個孔,
V3 需要的是**五條各自獨立、彼此不交叉、且轉彎半徑不會夾線的路徑**。

轉彎半徑太小,線會磨斷或卡住。這條要當成幾何不變式檢查,不能等實體才發現。

## 實測:對指是算出來的,不是畫出來的

手指是平面連桿鏈,段長已知、關節極限已知,所以**指尖能到哪裡是算術**;
兩組可達集合會不會靠到接觸距離內,也是算術。這就是 `thumb_index_tip_gap_mm`。

| 量 | 值 |
|---|---|
| 對指後最近距離 | **20.7 mm** |
| 接觸判準 | 22.0 mm(指尖約 24×22,兩個半寬相加) |
| 拇指沒轉、留在指列裡 | **26.1 mm** ← 這就是那條斷言的鑑別力 |
| 掌寬 / 指距 | 114.0 / 30.0 mm |
| 手指長 / 拇指長 | 114.5 / 114.5 mm |

### 兩個被量測推翻的假設

1. **拇指不能靠「跟手指一樣長」變成拇指。** 當時手指是四節、鏈長 168.5 mm,拇指照抄會
   把指尖送到對面外側 78 mm——**任何姿態都在追過手指而不是碰到它們**,於是拇指被砍成
   114.5 mm。後來整手降到三節,手指也變成 114.5 mm,**兩者的規格因此完全相同**——
   同一個 `SingleTendonFingerSpec`、同一個零件號。這條量測的結論沒有被推翻,但它的**理由
   換了**:現在讓拇指成為拇指的不是鏈比較短,而是下面第 2 點的對生角與掌前凸台。
   鏈長相同這件事是刻意留著的,因為它讓十五個指節共用一個零件號。
2. **只把拇指轉個角度沒有用。** 拇指根還必須**站在掌面前方**,否則它只在手指所在的平面裡
   擺動,永遠只能側對側相遇。`thumb_base_palmar_mm` 就是這件事,而它的上限是掌盤自己的
   厚度(22 mm)——再往前拇指就長在一根伸出手掌的柱子上,那能碰到食指尖,但不是拇指。

四個擺位參數是**掃描出來的**,不是憑感覺:在物理合理的範圍內對 `thumb_index_tip_gap_mm`
掃描。其中前傾與下降兩個都停在邊界上,那是誠實的結果而不是巧合——拇指根想要盡量往前、
盡量往上,是約束在頂著它。

## 實測:組裝起來的手

| 量 | 值 |
|---|---|
| 零件 | 1 個掌盤 + 15 個指節(四指各 3、拇指 3) |
| 非流形邊 | **0** |
| 不同手指之間的靜止干涉 | **0 對** |
| 組裝包絡 | 140.0 × 44.1 × 265.5 mm |
| 掌盤單件 | 140.0 × 44.0 × 103.5 mm,2 686 三角面 |
| 指節單件 | 24.0 × 22.0 × 67.0 mm |

**組裝後 265.5 mm 超過 256 mm 床身,這是正常的**:零件分開印再組裝,每個單件都遠小於床身。
文件寫下這個數字是為了不讓人以為整隻手可以一次印出來。

### thenar 凸台的高度是推導出來的,不是填的

拇指基節掛在拇指自己的軸上一個節距處,而那個軸擺過掌盤 40°,所以**基節也跟著往下盪回掌盤**。
第一版凸台高 40 mm,和基節重疊 219 個面。改成從「基節軸向底端」推導,還剩 114 個面——
因為**傾斜物體的最低點不是它的軸向端點**:本體有寬有深,一傾斜就有角落盪到端點之下。
真正的最低點要把 `hypot(寬, 深)/2 × sin(擺角)` 算進去,量出來是 -24.76 而不是 -14.30。

最後凸台改成**整個坐在拇指根之下**(頂面就是根的高度),留 5.24 mm 餘裕。人手的大魚際也
長在關節下面而不是旁邊,理由一樣。
