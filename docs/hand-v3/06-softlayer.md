# 06 — 雙層手套與充氣夾層

> 回導航 [[hand-v3]] · 相關 [[hand-v3/07-interfaces]]、[[hand-v3/v6-scripts]]、[[hand-v3/v9-references]]

## 結構

兩隻手套套在剛性手上,**只在手腕袖口黏死一道**,留一個進氣口。
內層彈性(丁腈),外層**不可延展**(現成的耐用工作手套)。
手指閉合到物體上之後,用針筒往兩層之間打氣。

**不做氣密工程。** 只有一道密封,漏了再推一下針筒就好。這是刻意的取捨:
把它做成密封專案會憑空多出每指一條接縫、而且全在會反覆彎折的地方。

## 它為什麼會有效

`[親驗摘要]` arXiv 2510.27184 的結論是:提高內壓會讓**等效摩擦係數成比例上升**,
因此能在**不加大夾持力**的前提下抓起又重又滑的東西。arXiv 2502.00926 量到摩擦力
最多可差 **2.8 倍**。

所以主要收益**不是把物體推得更緊**,是摩擦係數本身變大。對一隻靠細線和小伺服
驅動的手,這比增加正向力有價值得多——線和伺服正是最弱的一環。

三個機制同時作用,依重要性排:

1. **接觸面積變大**——柔性膜包住不規則表面,剛性指節只點接觸。
2. **幾何互鎖**——膜陷進物體表面的凹凸裡。
3. **正向力增加**——氣壓把物體撐開一點點。這一項最小。

## 外層為什麼一定要不可延展

連通氣體的壓力**處處相同**,所以物體感受到的力 = 壓力 × 接觸面積,
跟手背鼓多大無關。「空氣跑到別的地方所以白費」是錯的說法。

真正的問題是**自由鼓起的那塊膜會把整包氣體的壓力封頂**。
鬆的橡膠氣球撐到大半徑時只需要很小的壓力維持,於是壓力就停在那個值,
再推針筒只是讓手背更鼓。文獻用的是 50–125 kPa;一隻鬆的丁腈手套大概十幾 kPa
就鼓起來了 `[推論,未量測]`。

外層撐不開 → 夾層只能往內擠 → 內側是剛性手指不會動 → 全部推向物體。

**這條物理是可被推翻的**,而且台架上換一隻手套就驗完了。若換工作手套後滑脫力
沒有變化,上面這段就是錯的,要照量到的結果改寫。對應
[[hand-v3/02-requirements]] 的 PS-6。

## 加壓與抽真空

兩種都做,共用同一個進氣口,因為這是**只變一個變數**的對照實驗。

| | 加壓(推針筒) | 抽真空(拉針筒) |
|---|---|---|
| 力的來源 | 夾層鼓起壓向物體 | 大氣壓把外層貼上物體 |
| 壓差上限 | 由手勁決定,`[轉引]` 20 mL 針筒可達約 220 kPa | **物理上鎖死在約 100 kPa** |
| 會不會爆 | 會,要加洩壓路徑或機械擋塊 | **不可能** |
| 力的方向 | 往阻力最小處鼓,需要外層約束 | **自動朝向物體** |
| 額外需要 | 無 | 夾層要填顆粒或多層薄膜才鎖得住形狀 |

抽真空那條就是咖啡渣夾爪的原理。它的安全上限是免費的。

## 安全

- **針筒推得到的壓力是文獻用壓的兩倍** `[轉引]`。加洩壓路徑或機械擋塊,
  不要靠手感。
- **不要用乳膠手套**——第一型過敏風險。用丁腈。
- 剛性手指與物體之間會夾傷,見 [[hand-v3/05-actuation]] 的安全段。

## 尚未證實

- 「閉合之後才充氣」這個時序,子代理宣稱文獻明確測過,**我讀摘要查不到**。
  當成合理設計,不當成已證實的結論。
- 熱塑性聚氨酯膜、丁腈手套的爆破壓,**查無驗證數字**。不要照猜的數字設計。
