# 07 — 幾何必須提供什麼(介面契約)

> 回導航 [[hand-v3]] · 相關 [[hand-v3/06-softlayer]]、[[hand-v3/04-palm-thumb]]

介面先定死,實作只能透過它說話。這一頁是**軟層與剛性手之間唯一的契約**;
兩邊各自怎麼做都行,只要都遵守這裡。

## 契約只有兩項

| 項目 | 在哪裡 | 幾何必須保證 |
|---|---|---|
| **袖口夾** | 手腕 | 一圈可以把兩層手套一起夾住的形狀,夾住之後不漏到「一次充氣撐不到十秒」的程度 |
| **進氣口** | 掌背或手腕側 | 一個貫穿孔,接得上針筒的公頭;**加壓與抽真空共用同一個** |

就這樣。**外層手套不在契約內**——它是現成品,雛型出來之後買一隻套上去,
零 CAD、零列印、零介面。內層也是現成的丁腈手套。

## 為什麼這麼少

因為使用者已裁定:氣囊本體與外層都留給實體實驗。幾何這一側只需要提供
「兩層手套能被固定住,而且氣進得去」。多做的每一項都是在還沒量到數字之前
先把設計凍結,那正好是最容易白做的順序。

## 幾何可驗的斷言

這兩項都是純幾何,Lane A 機器驗得了(對應 [[hand-v3/02-requirements]] 的 ES-4):

- 袖口夾的最小壁厚不低於既有規格的最小壁厚。
- 進氣口貫穿:射線從外面打進去要能穿出來,不能被內部結構擋住。
  這與 V2 每臂電線孔用的是同一種射線探針。
- 進氣口不與任何腱路徑相交。
- 充氣後的外形包絡不擋住手指閉合——把夾層當成一個幾何偏移面,
  餵進既有的掃掠機制(PS-4)。偏移量等 Track 1 量到再填。

## 待填(等 Track 1)

| 項目 | 由什麼決定 |
|---|---|
| 袖口夾的直徑與夾持行程 | 實際兩隻手套疊起來的厚度 |
| 進氣口的孔徑與位置 | 實際針筒接頭規格,以及手握著時哪裡不會被擋住 |
| 夾層的幾何偏移量 | 台架上量到的充氣厚度 |
