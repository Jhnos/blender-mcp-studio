# 靈巧手 V3 — 導航

> 回導航 [[README]] · 相關 [[tasks/00_INDEX]]、[[30-verification]]

V3 是一隻**單自由度線驅動的擬人手**:四指一排加對生拇指,每指三個指節由**一條腱**
連動閉合,外面套一組雙層手套,手指閉合後用針筒往夾層打氣以加強抓持。

它與 V1／V2 是**不同的機器**,不是同一條演化線。V1／V2 是五臂放射對稱、每臂四個
雙軸關節、二十條腱的章魚手,兩者都是 checksum 控管的凍結交付物,V3 一個位元組都不動。

**這棵樹是平鋪的**,因為 [[README]] 的孤兒閘門只走兩跳;子目錄會變成孤兒。
樹內互指一律寫 `[[hand-v3/03-finger]]` 這種從 `docs/` 根算起的完整路徑。
