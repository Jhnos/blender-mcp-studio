# v6b — 第一件實體:列印試片協定

> 回導航 [[hand-v3]]、[[hand-v3/v0-INDEX]] · 相關 [[hand-v3/v6-scripts]]、[[hand-v3/v8-results]]

[[hand-v3/v6-scripts]] 的台架協定量的是**抓持力**,那是很後面的事。
這一份量的是更前面、也更會擋路的一件事:**這個零件印得出來嗎**。

十五個指節共用一個零件號,所以**一個尺寸錯,十五件全廢**。先印一件。

判準是數字,不是手感。所有目標值來自 `HingePhalanxSpec`,不是這裡編的。

## 印什麼

`models/hand-v3/phalanx_mm.stl` — 24.0 × 22.0 × 67.0 mm。

| 設定 | 值 | 為什麼 |
|---|---|---|
| 單位 / 縮放 | mm / 100% | STL 已是 mm |
| 擺放 | **平躺**(檔案裡已經躺好) | 立著印,銷孔會變成階梯 |
| auto-arrange | **關掉** | 它會把已經算好的擺放轉掉 |
| 支撐 | 先不用 | 目的就是看無支撐橋接會不會塌 |

第一件**不要**改參數。要看的正是預設參數印出來會怎樣。

## 第一階段:一件,量三個孔

| # | 量什麼 | 目標 | 判準 | 沒過代表 |
|---|---|---|---|---|
| C1 | 銷孔直徑(兩個耳片各量一次) | Ø4.50 | **4.35–4.70 mm** | 偏小=收縮/出料過量,偏大=孔會鬆 |
| C2 | Ø4.0 銷能否**手推穿過兩個耳片** | 能 | 不用工具、不用力 | 銷孔沒對正或變形 |
| C3 | 軸承座直徑 | Ø8.10 | **7.95–8.20 mm** | MR84(Ø8×Ø4×3)壓不進或掉出來 |
| C4 | MR84 壓入後**不自己掉出來** | 是 | 倒過來搖不掉 | 座偏大 |
| C5 | 腱孔(掌側)通透 | Ø2.8 | **Ø2.0 線可穿過全長** | 橋接塌了把孔封住 |
| C6 | 走線孔(背側)通透 | Ø2.8 | 同上 | 同上 |
| C7 | 兩孔之間、以及孔到銷孔的壁 | ≥2.4 | 目視無裂、無穿 | 壁太薄 |

**每一項都要記數字,不要只記「OK」。** 「OK」在下一版沒有比較基準。

量法:游標卡尺量孔用內量爪,或用銷規。同一個孔量兩次(轉 90°),兩個值都記——
橢圓化是列印最常見的失效,而只量一次看不出來。

### 沒過怎麼辦

| 情況 | 下一步 |
|---|---|
| C1 偏小 / C2 推不過 | 這是**公差問題不是設計問題**:調流量或用 0.2 mm 層高再印一件,不要先改 CAD |
| C1 連調兩次仍偏小 | 才回頭改 `printed_radial_clearance_mm`(目前 0.25) |
| C3/C4 沒過 | 同上,先調機再改 `bearing_seat_diameter_mm`(目前 8.1) |
| C5/C6 塌孔 | 加支撐再印一次;仍塌則是橋接跨距問題,回報後改幾何 |
| C7 有裂 | 停,回報。`minimum_wall_mm`(2.4)可能不夠 |

## 第二階段:第二件,量關節

**只在第一階段全過之後才做。** 一件量不到配合——配合要兩件。

| # | 量什麼 | 目標 | 判準 |
|---|---|---|---|
| J1 | 舌片厚 / 叉口寬 | 5.0 / 5.6 | 兩側各約 0.3 mm 間隙,能合上不晃 |
| J2 | 插銷後能否轉動 | 能 | 手轉順,不卡不鬆 |
| J3 | 單向可轉角度 | ±50° | 用量角器,兩側各量 |
| J4 | 靜止時兩個本體之間的間隙 | 0.5 | **不可為 0**;為 0 代表相鄰件會互相頂 |

J4 是這一版特別要看的:借來的規格原本讓相鄰件互相侵入 2.5 mm,關節中心推到
27.0 mm 才換到 0.5 mm 的間隙——那 0.5 mm 在螢幕上是零風險,在實體上是**列印公差等級**。

## 記錄

**量完不要自己比對表格,交給機器判**:

```bash
python3 scripts/analyse_coupon.py --c1 4.52 4.48 --c2 yes --c3 8.05 8.12 --c4 yes --c5 yes --c6 yes --c7 yes
```

它從連桿規格算出 C1/C3 的公差帶(上表的數字由測試釘住,不會漂),逐項給 PASS / FAIL / VACUOUS,
並印出可直接貼進 [[hand-v3/v8-results]] 的列;只量一次的孔是 vacuous,全部七項 PASS 才 exit 0。

數字填進 [[hand-v3/v8-results]] 的「機器結果」表下面新開的「試片」段:
一列一次量測,同一個孔的兩次量測**分開兩列**,不要先平均。

母數不足就標 vacuous——**一件不是一個樣本數,是一個觀察**,別拿它算良率。
