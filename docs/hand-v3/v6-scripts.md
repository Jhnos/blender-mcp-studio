## 實體台架協定(抓持力)

> 第一件實體不是這一段——先看 [[hand-v3/v6b-coupon]]。這裡假設零件已經印得出來。

這一段是人執行,但**判準是數字,不是感覺**。照著做就好,不必自己設計。

### 每一次試驗

1. 記錄:物體編號、外層手套編號、氣壓方向、目標壓力、日期、第幾次。
2. 手指閉合到物體上,**維持腱張力不變**。
3. 依當次條件充氣或抽氣到目標值(或標記「未充氣」)。
4. 掛鉤掛在物體上,**每次加 50 g**,直到物體滑脫。
5. 記下滑脫前最後一個穩定的總質量,以及是否在 10 秒內滑脫。
6. 洩壓、鬆開、物體歸位。

滑脫力(N)= 總質量(kg)× 9.81。**兩個數字都記**,質量是原始觀察,力是推導值。

### 順序

S9–S11 的兩個條件必須**隨機交錯**,不能先做完一組再做另一組。
用擲硬幣或事先寫好的亂序表決定每一次的條件,並把該序列存檔。

### 判準

- **先看母數**:`n` 要等於計畫的 10,不足就標 vacuous,不併入 pass。
- **配對比較**:同一件物體的兩個條件成一對,算每對的差值。
- **報效果量與信賴區間**,不報「有變好」。信賴區間跨過 0 就是**沒測到差異**,
  不是「差異很小」——這兩句話意思完全不同。
- 統計方法照 `applied-statistics:experiment-statistics`,不自己發明檢定。
  **算式與讀表都已經寫好了。** 你只負責把數字填進 [[hand-v3/v8-results]] 的試驗表,
  然後跑一行:

```bash
python3 scripts/analyse_bench_results.py --sesoi 0.5
```

  `--sesoi` 是**滑脫力差多少才算有用**(牛頓),沒有預設也不會有——那是關於這隻手的決定。
  配對差、效果量、信賴區間、多重比較校正、以及不顯著時的等價檢定,全部由它算。
  沒填的場景會回報 `vacuous` 並附上母數,不會混進 pass。

### 它會做什麼,以及為什麼

| 步驟 | 做法 | 為什麼不是別的做法 |
|---|---|---|
| 先看母數 | 不足計畫的 10 對 → **vacuous**,永遠不併入 pass | 母數 0 算比例會得到 1.0,那是假綠 |
| 檢定 | Wilcoxon 符號等級,**精確枚舉**(n ≤ 20) | 十對做常態性檢定幾乎沒有鑑別力,用它挑分支是把儀式當嚴謹 |
| 效果量 | 配對等級雙序列相關(−1 ~ +1) | 無母數分支要的是序數效果量,不是 Cohen's d |
| 不確定性 | 中位數的自助信賴區間,**種子固定** | 每次跑出不同答案的東西不叫判準 |
| 多重比較 | Holm,家族 = S9–S12 四個場景 | 少數確認性比較用 Holm;不反射性套 Bonferroni |
| 不顯著時 | 對 **SESOI** 跑等價檢定(TOST) | 「沒測到差異」不等於「沒有差異」——這是最常犯的那個錯 |

**SESOI(最小值得在意的效果)沒有預設,而且永遠不會有。** 滑脫力要差多少才算「有用」,
是關於這隻手的決定,不是函式庫常數。跑分析時必須給,給 0 或負值會直接拒絕。

### 安全

- 針筒推得到的壓力可達文獻用壓的兩倍。**加洩壓路徑或機械擋塊**,不要靠手感。
- 手不要放在閉合路徑上;馬達要限流。
- 張線時戴護目鏡。
- 用丁腈,不要乳膠。

### 什麼情況要停下來

- 手套接縫出現可見裂痕 → 停,換新的,並記下那一組已經跑了幾次。
- 同一件物體連續三次結果差異超過一半 → 停,檢查腱張力有沒有漂移。
