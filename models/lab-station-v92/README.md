# 量測工作站 v92

沿用 v91 的 76 個原件身份。局部修改後蓋退讓面、36 個短通風槽、兩塊下臂承面及兩支平頭 D 銷。其餘 70 件 STL 保留原始位元組，八支共用連桿與四片可換齒盤照舊。整機圖、動作和列印包的來源指紋見 `驗證/synchronized-native-result.json`。

- 組裝模型為 `量測工作站-v92.blend`。76 件 STL 分件存於 `STL-整機76件`。
- `P2S-PLA-76件單盤-已切片-v92.3mf` 為 Bambu P2S、PLA、0.4 mm 噴嘴、0.2 mm 層高的已切片單盤，76 件均有本體接床刀路。後蓋翻面排版，支撐刀路包絡與受檢退讓面相離約 0.324 mm，八個鉸鍊見證點下方有支撐。短槽最長取樣橋接刀路 3.75 mm。
- 後蓋在 90° 時的 170 × 40 mm 直進維修通道，以五個螢幕角度和封閉實體求交核對。藍框為驗證包絡。
- 可拆支撐與 brim。實際黏附、免修整配合、負載、熱性能與硬體介面待實測。
