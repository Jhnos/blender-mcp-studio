# v80：P2S 單盤切片檢查

主檔：P2S-PLA-69件單盤-已切片-v80.3mf。包含機型／材料／製程設定及內嵌 G-code；以 Bambu Studio 開啟。未連線或啟動印表機。此版本為實際切片工作檔，不再只是幾何排版。

## 原零件與檔案

69個實際列印零件沿用v78，方向／位置沿用v79。STL/列印零件全部逐位元相同；未覆寫v34、v78、v79。整機原模型-v78-幾何未改.blend是原生模型的相同副本，包含原本完整113模型（其中44個是參考件，不加入列印）。12個1.4 mm止扣保持平放；長臂與部分外殼保持直立。

保存後的69個網格通過獨立CGAL封閉／自交檢查；三角面索引完全相同，拓竹序列化座標最大變動約0.0000054 mm，未做自動網格修補。檔內G-code與實際切片輸出一致，已由Bambu Studio --info重新讀入成功。

## 切片設定與檢查

Bambu Studio 02.08.02.61，原廠P2S 0.4 mm設定；Generic PLA、模型層高0.2 mm、三道外牆、15% gyroid、整層一起印。假設使用紋理PEI板，平台55°C、噴嘴220°C、首層20 mm/s。材料品牌與實際底板尚未由使用者確認。

一般自動支撐（snug），允許支撐從模型上生長；上下接觸間隙0.2 mm，外側brim 3 mm、與模型間隙0.1 mm。3 mm是設定寬度；狹窄零件間隙的實際brim會被切片器裁切，不能宣稱每件周圍都有完整3 mm。

一個切片盤，69件都有實際首層本體擠出路徑。檢查所有支撐／brim／模型擠出線的名目線寬外緣及圓弧：XY範圍約1.136～251.864 mm，沒有床面越界樣本。切片結果沒有回報物件間路徑衝突，warning_message為空。模型層高是0.2 mm，但支撐會插入不同高度；G-code共有6105個CHANGE_LAYER事件，不應誤寫成全部只有1150個事件。

預估約44小時15分、1588 g PLA（含支撐與黏附等用料）。單一1 kg料捲不足；必須準備足量供料或續料安排。這是一個單盤工作，不是已證實可無人看管完成的工作。

## 支撐與黏附的實際限制

實際首層圖：藍色模型、綠色支撐、橘色brim。69件首層本體面積另附CSV：最小旋鈕約3.79 mm²，8支長臂約22～24 mm²；依靠brim和支撐協助穩定，部分支撐底面沒有額外完整brim。軟體能確認路徑與接觸配置，不能確認底板清潔度、PLA配方、翹曲、長臂擺動、層間強度與關節公差。長臂仍是沿高度方向列印，承載資格尚未建立。

本版需要移除PLA支撐與brim，不能承諾免後加工。若要把長臂全部平放以改善強度或大幅增加黏附面，仍可能要改成多盤；未為了維持單盤而改零件形狀。

## 不採用的候選與保留診斷

樹狀支撐在托盤／頂蓋間產生實際G-code衝突，不採用。一般支撐6 mm brim沒有物件路徑衝突，但床邊裁切後，按名目線寬外緣計算約超界0.021 mm，因此改3 mm重切。另試最小旋鈕及兩個背蓋旋鈕平放，雖能排齊69件，卻新增A旋鈕／肩部旋鈕路徑衝突，亦不採用。最終採用通過的原位置＋一般支撐＋3 mm brim。

原始日誌保留Voronoi回退診斷及「Invalid T command (T65535)」：T65535存在於未修改的官方P2S結尾指令中；官方CLI最終return_code為0，未刪改原廠結尾來壓掉訊息，也未經實際韌體執行。首次3MF匯出曾把完整路徑重複串接，已改用檔名並重新切片成功；失敗日誌另存。

檢查結果包含正／負對照、原STL雜湊、保存網格檢查、逐面來源對照、切片器回報、完整原始日誌、路徑審核與設定。這些是本次離線模型／切片檢查，未接入正式MCP／CI，未變更服務或解決既有軟體CI失敗。
