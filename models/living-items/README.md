# Veilroom 小物來源

六件低多邊形小物：鑰匙、信件、藥瓶、錢袋、工具（槌子）、任務包裹。
`living-items.blend` 可直接開啟，預設顯示六件組裝預覽，所有材質內嵌，沒有外部貼圖。
本包是素材來源；遊戲背包與互動接入另由 Veilroom 内容包完成。

## 尺寸與重編

- 單位為公尺，每件放入一公尺地格；各 `LI_<id>_root` 是地面原點。
- 預覽把六個 root 沿 X 軸排列。單物件重渲染先把選定 root 移回 `(0,0,0)`，並將其他五件集合內物件的 **渲染可見性** 關閉。
- 地面圖：選 `LI_ground_camera`，128×192、100%，腳底像素 `(64,144)`；沿用 World Kit 真正的正交鏡頭。
- 背包圖：選 `LI_inventory_camera`，64×64、100%，中心錨點 `(32,32)`。
- 組裝預覽：root X 依序為 −2.375、−1.425、−0.475、0.475、1.425、2.375，全部顯示；選 `LI_preview_camera`，1536×512。
- 重新生成需在 Blender Universal Room checkout 執行 `scripts/model_living_items.py`；依賴既有 generator runner、材質工具、發布契約及 `models/world-kit/world-kit.blend`。
- `scripts/verify_living_items.py` 重新開啟來源，檢查六件幾何、材質、原點、相機投影、透明邊緣並重渲染十二張逐像素比較。結果在 `verification.json`。

## 獨立畫面檢查目標

逐張檢查十二張小圖及組裝預覽，不以預覽替代背包圖檢查。
1. 六件預覽完整呈現且相互分離，無圖邊裁切。
2. 各地面圖與背包圖都有完整物件，四周留透明邊，無不相關物件或背景。
3. 鑰匙可見環形匙頭、匙身與齒；信件可見封口線與封蠟。
4. 藥瓶可見瓶身、瓶頸、塞子與正面標籤；錢袋可見袋體與束口繩。
5. 槌子可見金屬頭與握柄；包裹可見盒身、交叉緞帶與標籤。
6. 包裹交叉緞帶接合處沒有黑洞、破面或交錯斑紋；六種物件輪廓不相互重疊。
此為可見構成與幾何檢查，不推論真人辨識率、喜好、遊戲尺寸或操作結果。
