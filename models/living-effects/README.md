# Veilroom 互動特效來源

六組可編輯低多邊形特效，每組 8 幀、128×128 RGBA、12fps，單次播放約 667ms。
順序為拾取光點 pickup、解鎖光環 unlock、任務完成 complete、腳步塵 footsteps、傳送旋流 teleport、操作受阻 blocked。
本包僅提供視覺素材，事件結果、道具與位置仍由 Veilroom 的權威服務決定；尚未接入遊戲。

## 可編輯來源與輸出

- 開啟 `living-effects.blend` 可見六組排列的第5幀預覽，材質內嵌，無模擬快取或外部貼圖。
- 每組 `LF_<id>_root` 是效果原點；各 mesh 有命名的 `*_oneshot` 動作，第1–8幀可編輯。
- 單組重渲染：選定 root 移回 `(0,0,0)`，關閉其他集合內物件的渲染可見性；選 `LF_camera`，128×128、100%、12fps，渲染第1–8幀。
- 正交相機採 World Kit 方向，效果中心原點為 `(0.5,0.5)`。全組用 NORMAL alpha 混合，播放完應移除，不無限循環。
- 減少動態模式的候選靜態影格是索引4（Blender第5幀）；文字結果仍由遊戲呈現，不靠顏色傳達結果。
- 預覽：六個 root 的 X 依序為 −5.25、−3.15、−1.05、1.05、3.15、5.25；全部顯示，`LF_preview_camera`，1536×512，第5幀。
- 在來源 checkout 執行 `scripts/model_living_effects.py` 重新生成；沿用 generator runner、共用材質與 World Kit 相機。
- `scripts/verify_living_effects.py` 重開保存檔、檢查8個不同姿態、48幀投影與透明邊界，重渲染全部48幀並逐像素比較。結果記於 `verification.json`。

## 獨立畫面檢查目標

逐一檢查六組各8幀及組裝預覽，允許建立檢查用接觸表。
1. 每幀存在非空圖形、四周透明、不碰圖邊，沒有其他組的物件。
2. pickup：金色小光點向上移動；unlock：綠色環及四個外擴點。
3. complete：中央勾形記號與外圍放射線，無破面或黑洞。
4. footsteps：兩排棕色低矮塵團，隨影格擴散；teleport：紫色雙環及沿周圍移動的光點。
5. blocked：紅色交叉與外圍短線，不把成功符號誤當阻擋符號。
6. 組裝預覽六組完整分離；逐幀構成可見變化，形狀／顏色能分組。
僅判斷檔案中直接可見的構成、邊界與幀間差異；不推論真人辨識率、遊戲播放、效能或主觀喜好。
